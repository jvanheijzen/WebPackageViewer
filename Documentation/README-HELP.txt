WEB PACKAGE TOOLS HELP

WebPackageTools-Administrator.html is internal-only. Do not distribute it with course EXEs.

WebPackageCourses-Distributor.html is safe for distributor-facing help and may be embedded into WebPackageViewer.

The HTML files are self-contained: CSS, JavaScript and screenshot images are embedded in each file. The screens folder is retained only as editable/source artwork.

Recommended integration: use the Stage 8 HelpWindow/HelpLauncher source package rather than CHM. This avoids the legacy HTML Help compiler and CHM Mark-of-the-Web/network restrictions while using the WebView2 runtime already required by the applications.
