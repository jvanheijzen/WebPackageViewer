Distributor Guide

Offline Course Package Distributor Guide

Instructions for running the supplied offline course EXEs, activating a computer, understanding course-level licensing, using fullscreen, and collecting the information support needs.
Revision: August 2026 · Based on the supplied Web Package Tools source package

What you receive

Your course is delivered as one or more standalone Windows EXE files. Each EXE contains one offline HTML5 course module and does not require the Web Package Tools administrator software.

If the course is licensed, the first launch on a computer may ask for activation. Your course administrator will use the Course ID and Machine ID shown by the package to create a small license file for that computer.

One course license covers all modules in that course on the same computer. You do not need a separate license for every module when they share the same Course ID/Product Code.

Open a course module

Offline course viewer — rendered from the current WPF layout.
  1. Copy the supplied course EXE files to a local folder where you have permission to run them.
  2. Double-click the desired module EXE.
  3. If the computer is already licensed for that course, the module opens. If not, the Offline License Required window appears.

No internal Web Package Builder or License Generator is required on the distributor computer.

Activate this computer

Offline License Required window — rendered from the current WPF layout.
  1. Click Copy. This copies the Course ID and Machine ID to the Windows clipboard.
  2. Send that information to your course administrator using your normal support channel.
  3. When you receive the .wpl license file, return to the activation window and click Import License....
  4. Select the supplied .wpl. If it is valid for this course and computer, the application confirms activation and opens the course.
Do not edit the license file. A modified, mismatched, expired, or machine-incompatible license is rejected.

How the course license works

  • The license is tied to the displayed Machine ID and the course ID.
  • The same valid license unlocks every module packaged as part of that course on the same computer.
  • A license may be permanent or may contain an expiration date.
  • If a license expires, the course will request a replacement license.
  • A license copied to another computer is not expected to work because that computer has a different Machine ID.

Viewer and fullscreen

The course runs inside a Windows WebView2 viewer. Standard window controls are available in the title bar. When the HTML5 course player requests fullscreen, the viewer expands to the full physical monitor, including the taskbar area, and restores the prior window state when fullscreen ends.

Course-specific navigation, audio, captions, progress controls, and fullscreen buttons are provided by the published course content itself and may vary by module.

Using another computer

Moving or copying the EXE files to a different computer does not transfer the license. Launch a module on the new computer, copy its new Course ID and Machine ID, and request a license for that computer.

Reinstalling Windows or major machine-identity changes can also result in a different Machine ID. If an existing license stops matching after a system change, send the newly displayed Machine ID to the course administrator.

Troubleshooting

Message / symptomWhat to do
Course is not activated on this computer.Copy the Course ID and Machine ID and request a license.
License is for a different course.Confirm you selected the license supplied for this course.
License is for a different computer.Request a new license for the Machine ID shown on this computer.
Offline license has expired.Request a renewed license.
Selected license file is invalid / invalid signature.Do not edit the file. Request a fresh copy from the course administrator.
Protected package or integrity error.Replace the course EXE with a fresh copy supplied by the course administrator.
WebView2 initialization failed.Contact your IT department or course administrator. The Microsoft Edge WebView2 Runtime may need repair or installation.
Course opens but content/player behaves unexpectedly.Close the module, reopen it, and if the issue remains provide the course/module name and a screenshot to support.

Information to send for support

For activation or license problems, send the exact text produced by the Copy button in the activation window. For other problems, include:

  • Course/module EXE name
  • Course ID and Machine ID when available
  • Exact error message
  • Screenshot of the problem
  • Whether the module worked previously on this computer

Do not send administrator tools, signing-key backup files, or any internal licensing material.
